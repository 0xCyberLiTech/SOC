# Security Policy — Vitrine SOC Extreme HUD

## Périmètre

Ce dépôt présente la vitrine d'architecture, la doctrine de détection et les interfaces du SOC homelab **0xCyberLiTech**.
Il s'agit d'une présentation publique de cybersécurité défensive — aucune donnée de production ni information
sensible n'est stockée dans ce dépôt. Toutes les adresses IP affichées dans les illustrations sont anonymisées
conformément aux standards de publication souverains.

---

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité dans ce dépôt (secret exposé, faille dans un script,
mauvaise pratique de sécurité), merci de la signaler de façon responsable.

**Ne pas ouvrir d'issue publique pour une vulnérabilité de sécurité.**

### Contact

Ouvrir une **GitHub Security Advisory** privée :
→ [https://github.com/0xCyberLiTech/SOC/security/advisories/new](https://github.com/0xCyberLiTech/SOC/security/advisories/new)

### Informations à fournir

- Description de la vulnérabilité
- Fichier(s) concerné(s) et numéro(s) de ligne
- Impact potentiel
- Étapes pour reproduire (si applicable)
