# <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-shield.svg" width="20" height="20" align="absmiddle" alt="" /> Security Policy — Vitrine SOC Extreme HUD

## <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-plan.svg" width="18" height="18" align="absmiddle" alt="" /> 01 // Périmètre
<img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-section-cyan.svg" width="100%" alt="" />

Ce dépôt présente la vitrine d'architecture, la doctrine de détection et les interfaces du SOC homelab **0xCyberLiTech**.
Il s'agit d'une présentation publique de cybersécurité défensive — aucune donnée de production ni information
sensible n'est stockée dans ce dépôt. Toutes les adresses IP affichées dans les illustrations sont anonymisées
conformément aux standards de publication souverains.

---

## <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-plan.svg" width="18" height="18" align="absmiddle" alt="" /> 02 // Signaler une vulnérabilité
<img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-section-cyan.svg" width="100%" alt="" />

Si vous découvrez une vulnérabilité dans ce dépôt (secret exposé, faille dans un script,
mauvaise pratique de sécurité), merci de la signaler de façon responsable.

**Ne pas ouvrir d'issue publique pour une vulnérabilité de sécurité.**

### <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-target.svg" width="18" height="18" align="absmiddle" alt="" /> Contact

Ouvrir une **GitHub Security Advisory** privée :
→ [https://github.com/0xCyberLiTech/SOC/security/advisories/new](https://github.com/0xCyberLiTech/SOC/security/advisories/new)

### <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-target.svg" width="18" height="18" align="absmiddle" alt="" /> Informations à fournir

- Description de la vulnérabilité
- Fichier(s) concerné(s) et numéro(s) de ligne
- Impact potentiel
- Étapes pour reproduire (si applicable)
